隐私与数据说明

更新日期：2026 年 10 月 21 日

本地声音数据

新版中的声音检测需要麦克风授权。声音记录、声级、名称、备注和可选位置保存在本机；应用不会将这些内容提供给广告平台。位置仅在你主动开启并授权后附加到本地记录；为把坐标显示为可读地址，应用会使用 Apple 位置服务进行逆地理解析，网络不可用时保留坐标。你可以删除记录，卸载应用会移除本地数据。

主动分享与购买

当你主动导出或分享时，文件会交给系统分享功能及你选择的接收方。结果和导出文件标明数据仅供参考、非权威测量。应用内购买由 Apple 处理，开发者不接收银行卡信息。

广告与隐私选择

免费版包含 Google AdMob 与 User Messaging Platform（UMP）。仅在你启用广告服务并完成适用的隐私选择后请求广告；免费版含广告，Pro 免广告；你可以在设置 → 广告与隐私选择中管理适用的地区隐私授权。拒绝个性化或跟踪不等于免广告，实际投放以适用授权状态为准。Pro 不请求或展示广告，录音过程中不请求广告。我们按非个性化广告配置请求，在未获得系统跟踪授权时不传递 IDFA；关闭发布商第一方标识及个性化配置不意味着广告 SDK 不处理其他数据。

Google SDK 可能处理 IP 地址及由其推断的大致位置、设备或应用标识、广告展示和互动、产品互动、崩溃与性能诊断数据，用于广告投放、衡量、分析及防止欺诈。录音、声级记录、名称、备注和你附加到本地记录的位置不提供给广告服务。详见 Google SDK 数据披露与 Google 隐私政策。适用地区的隐私表单与撤回入口由 UMP 提供。

使用统计与性能监控

我们集成友盟 U-App（移动统计），U-APM 自动性能监控因兼容性问题暂未启用，服务提供方为友盟同欣（北京）科技有限公司。仅在单独隐私授权及系统跟踪授权后初始化 SDK，用于功能使用分析及录音启动、导出等操作耗时统计。SDK 可能处理设备标识、IP 地址、网络与设备信息、系统和应用版本、操作事件以及崩溃和性能诊断信息。录音、声级读数、位置、名称和备注不作为埋点内容上传。应用不启用网络内容监控、页面内容自动采集及远程日志回捞。拒绝不影响录音和本地功能。可在设置 → 使用统计与性能中关闭业务事件上报；性能采集的完全停用需要退出并重新打开应用。可通过 友盟数据删除入口行使删除权，详见 友盟隐私政策。

网站托管

本说明及支持网站由 GitHub Pages 托管。访问网站时，GitHub 可能处理 IP 地址及服务请求日志以提供和保护服务，参见 GitHub 隐私声明。网站不嵌入广告或分析脚本。

测量说明
